# ArKnights Perch · 方舟栖所（ArkP）

ArKnights Perch 是面向《明日方舟》世界观的安卓角色对话应用，内置干员档案与设定约束，接入用户自备的云端大模型，进行长期、连贯、贴合设定的对话。

| 项目 | 内容 |
|---|---|
| 当前版本 | 0.2.2 |
| 包名 | `cn.wisadelz.perch` |
| 系统要求 | Android 8.0 及以上 |
| 安装包 | 通用包，不区分处理器 |
| 分发方式 | 闭源分发，不提供源代码 |
| 更新通道 | 稳定版 / 公测版（设置内切换） |

## 这是什么

ArkP 把《明日方舟》的干员档案、剧情设定与关系网整理成结构化数据，内置到应用里；对话时由应用负责拼装提示词、约束角色行为、管理长期记忆，再把请求直接发给你配置的模型服务商。

它不做本地推理，也不自建中转服务：模型能力与费用全部来自你自备的 API Key，对话数据留在你自己的设备上。

## 主要功能

- **首次启动引导**：全新安装后三页说明本机保存什么、为什么需要自备模型、接入要走哪三步，可直接跳到「设置 → 模型」。
- **操作指引**：首次进入主要页面时，分步高亮关键位置并给出一句说明，覆盖干员列表、干员档案、对话列表、聊天与「我」页；每段只出现一次，可随时跳过，设置 → 教程 内可关闭或重新播放。
- **使用教程**：设置 → 教程 →「打开使用教程」可查阅完整说明，按十个主题分章展开，逐条列出要点。
- **模型接入指引**：设置 → 模型 顶部入口，讲清服务商自选、密钥取得与保管、三项填写、连接校验结果与排查路径；不推荐、不排序、不评价任何服务商。
- **接入与故障提示**：未接入模型时常驻提示，点击直达接入指引；Key 无效、额度不足、模型或地址有误时出现配置故障提示，限流、超时与断网不误报。
- **干员档案**：400 份内置档案，中文表单可查可改；首次保存保留原始档案，支持一键重置。
- **立绘与衣橱**：切换当前立绘，聊天中的着装描述随之变化。
- **流式对话**：逐字渲染、可中途停止并保留已产出内容；支持重新生成，重新生成会完整回退该轮回复及其记忆与信赖。单聊的多段回复自动拆成独立气泡，群聊中每位干员每轮只输出一条对白。
- **多角色群聊**：把多位干员放进同一个会话；可设置群名与群公告，按发言模式、发言条件、发言欲望与发言顺序决定本轮由谁接话，也可冻结指定成员的记忆或为群聊单独设置时间基准。群内支持成员管理、聊天记录搜索、恢复已删除记录与清理记录。
- **三级记忆**：短期 / 中期 / 长期记忆在后台整理并带入后续对话；另有心情状态与信赖值（含增减历史）。
- **记忆语义召回**：发送消息时按本轮话题从该干员过往记忆中挑出最相关的内容交给模型，减少话题脱节与重复；索引与检索全部在本机完成，不上传对话内容，设置内可开关并选择检索强度。
- **同义词增强**：换一种说法也能想起对应的往事（例如问「害怕」时想起写着「恐惧」的记忆）；干员名与其称呼不参与扩展。该功能默认开启。
- **自定义设定**：全局与干员专属两级作用域，支持关键词触发、IP 硬约束、插入位置、优先级与防递归。
- **本地词典检索**：对话时自动检索内置世界观词典，把相关官方设定作为事实依据交给模型，减少凭空编造；设置内可关闭。
- **多模型顺序路由**：支持 DeepSeek、阿里云百炼、智谱、月之暗面 Kimi、硅基流动、OpenAI、Gemini、xAI、Azure OpenAI、Anthropic Claude 十家预设，也可自定义 OpenAI / Anthropic 协议；按列表顺序尝试，前面的不可用会自动改用下一套。新增或编辑时先做一次最小连通性测试，通过才保存。
- **导入 / 导出**：聊天记录、干员记忆与设置可合并导出为 ZIP，导入时严格校验，不含 API Key。
- **更新与公告**：手动检查更新或开启自动更新（下载完成后由你确认安装）；启动时拉取官方公告，稳定版只接收稳定版公告，公测版会同时接收两种公告并展示较新的一条。
- **调试终端**：记录端点、模型、耗时与用量，不含对话正文与 Key，可复制或导出。
- **界面音效**：发送、收到回复、生成完成与记忆总结等操作可播放短提示音，音量跟随系统提示音，静音模式下不响；默认关闭，可在设置 → 声音中开启。
- **图标切换**：设置 → 外观 下可在「原色 / 极简」两套应用图标间切换，默认原色。
- **反馈工单**：设置 → 反馈 可直接提交功能建议、问题反馈或安全漏洞三类工单，最多附 3 张截图；提交过的工单在下方列表里随时查看进度，点开可看详情与维护者回复，也能对自己的说明补充、修改或删除。工单进度与当前设备绑定。

逐项的对象说明与变更记录见 `CHANGELOG.md`。

## 安装与首次使用

1. 取得安装包（分发渠道提供的安装包）。
2. 在系统提示中允许「安装未知应用」，完成安装。
3. 首次启动会看到三页说明：点「前往接入」直接进入「设置 → 模型」，点「暂不接入」先浏览；不需要操作指引时可点「跳过新手教程」。升级安装、恢复备份或已经配好 Key 的用户不会看到引导。
4. 干员数据在后台导入（干员页显示进度），导入期间其余页面可正常浏览。
5. 在「设置 → 模型」选择服务商并新增一套配置：API 地址、模型、API Key，按需设置思考模式与强度。保存时会先发送一次最小测试请求，**可能消耗少量 token**。不确定怎么填时，可先看页面顶部的「模型接入指引」，或查阅「设置 → 教程 → 打开使用教程」。
6. 从「干员」页选择干员，进入档案后点「开始聊天」。

升级说明：版本号只增不减，可直接覆盖安装；若应用来源与签名不一致，系统会拒绝覆盖，此时需要先导出备份、卸载旧版再安装。

## 数据与隐私

- 会话、消息、干员档案、自定义设定、记忆、状态、信赖值、用量统计与模型配置全部存放在本机；系统自动备份已关闭。
- API Key 由设备密钥加密后保存，落盘的只有密文；解密后的明文只存在于运行内存，不写文件、不进日志、不随导出与备份迁移。
- 换机、清除应用数据或卸载后，已保存的 Key 无法再解开，需要重新填写（这是预期的安全行为）。
- 对话内容不上传；只有你发请求时，提示词才会发送给你选择的服务商。世界观素材、公告与安装包由官方分发站点提供。

完整的安全设计与报告渠道见 [SECURITY.md](SECURITY.md)。

## 更新

- 设置页可手动「检查更新」，也可开启「自动更新」；自动更新只下载，安装动作始终由你确认。
- 新版本说明、公告与安装包由官方分发站点 `https://arkp.wisadelz.cn` 提供。
- 稳定版通道只接收正式版本；公测版通道会同时接收正式版与公测版，并提示其中较新的一个。

## 已知边界

- 未配置 API Key 时只做本地模拟回复，不产生真实用量。
- 应用被系统彻底关闭后，正在生成的回复会中断；该轮按中断处理，可重新发送。
- 心情状态、分级记忆与信赖值依赖模型可用；后台整理失败只留诊断日志，不打断聊天。
- 服务商若不支持流式用量或输出长度参数，保存验证或对话可能直接报错，需要换用兼容的服务商。
- 部分模型对「玩笑」与「伤害」的判断带有自身误差，信赖值变化可能与你的预期不完全一致。
